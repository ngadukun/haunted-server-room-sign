## The line

WARNING: This server room is haunted. The ghost unplugs cables, restarts servers, and still has better uptime than IT.

## Run it

```sh
python3 main.py
```

Running it prints the sign and writes it to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
